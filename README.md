# SuperNova Engenharia

Landing page institucional da SuperNova Engenharia, criada para apresentar serviços e gerar solicitações de atendimento em Florianópolis e Grande Florianópolis.

## Publicar uma prévia na Vercel

1. Envie esta pasta para um repositório Git ou importe-a diretamente na Vercel.
2. Crie um novo projeto na Vercel e mantenha o diretório raiz como este projeto.
3. A Vercel reconhecerá `vercel.json` e publicará a pasta `dist` sem etapa de build.

## Antes da publicação oficial

O formulário é demonstrativo. Conecte-o a um canal de atendimento real (e-mail, WhatsApp ou CRM) e atualize os seguintes dados quando estiverem disponíveis:

- telefone/WhatsApp;
- endereço;
- Instagram;
- projetos e fotografias autorizadas;
- dados institucionais e política de privacidade.
